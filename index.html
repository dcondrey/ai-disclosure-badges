AI Disclosure Badge Generator

Answer a few questions; get the badge that matches, with no need to pick a category yourself. Badges cite the W3C AI Content Disclosure vocabulary.

Does this badge need to say something different about the code versus the description?

Most PRs, commits, and docs are one badge covering the whole contribution. Split only when the two genuinely differ — e.g. the code is human-written but the PR description was AI-drafted.

One question at a time, starting from human-only. Answer No and you stop there — that's your badge. Answer Yes and you move one step further toward fully AI-authored and unreviewed. Changed your mind? Use ← Back at any point.

Optional note on human involvement

Free text, e.g. "reviewed for factual accuracy" or "AI drafted, human rewrote throughout." This is not part of the W3C specification's controlled vocabulary — it's a plain-language note carried in the badge's title/alt text, not a new disclosure category.

Pick a value for each half

Two badges, one for each half, meant to sit next to each other with no gap. Not part of the W3C vocabulary itself — each half still cites one of the three spec-defined values.
